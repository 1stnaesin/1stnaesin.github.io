예비고3은 수능 범위 전체를 실전 문항으로 다시 정리합니다.

  1. 1–2주
    독서의 기초와 태도개념 정리 → 교과서·부교재 예제 → 서술형 쓰기 → 단원 테스트
  2. 3주
    읽기 평가와 쓰기 전략개념 정리 → 교과서·부교재 예제 → 서술형 쓰기 → 단원 테스트
  3. 4–5주
    분야별 글 읽고 쓰기개념 정리 → 교과서·부교재 예제 → 서술형 쓰기 → 단원 테스트
  4. 6주
    목적별 글쓰기개념 정리 → 교과서·부교재 예제 → 서술형 쓰기 → 단원 테스트
  5. 7–8주
    통합·매체·공동체개념 정리 → 교과서·부교재 예제 → 서술형 쓰기 → 단원 테스트

배정·재학 중인 학교의 교과서 출판사와 부교재가 정해지면 그 학교 기준으로 예제와 시험 범위를 바꿉니다. 주 2~3회 1:1 수업 + 매일 플래너 점검 기준입니다.

독서와 작문 내신에서 점수가 갈리는 곳

  • 과학·기술 지문(비문학)은 수능 고난도 영역입니다. 겨울방학에 하루 2지문씩 시간을 재고 읽습니다.
  • 작문 문항은 초고와 고쳐 쓴 글을 비교하는 형식이 많아 고쳐쓰기 원리를 정리합니다.
  • 한 권 이상의 책을 길게 읽는 독서 활동이 수행평가로 자주 나옵니다.
